## 📖 About

Directory Opus is a professional file management suite developed by GPSoftware, an Australian studio that has been building file manager tools since the Amiga era. It replaces the standard Windows Explorer shell with a dual pane commander style layout, folder tabs, a customizable toolbar system, saved layouts, an advanced rename engine with regular expression support, FTP and archive handling, and an internal viewer that previews documents, images and media without launching external apps. The 2026 edition continues the long running 13.x line with refreshes to the search index, the scripting interface and dark mode consistency across all dialogs.

If you came looking for a Directory Opus download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. Everything here is written for a first time installer who wants to know what to expect before running setup.

## 🔑 Features

| 🌗 **Dual pane layout** | Two folder views side by side, with source and destination targets for fast copy and move operations. |
| 🗂️ **Folder tabs and groups** | Open many folders as tabs, save them as tab groups, and restore whole workspace layouts. |
| 🔤 **Batch rename engine** | Rename thousands of files with patterns, regex, numbering sequences and metadata tokens. |
| 📦 **Archive support** | Browse and extract ZIP, 7z, RAR and TAR archives directly inside the file list. |
| 👁️ **Internal viewer** | Preview images, text, PDFs, Office documents and media without opening another program. |
| 🎨 **Toolbar customization** | Build your own buttons, menus and hotkeys with a visual editor and scripting hooks. |
| 🔍 **Advanced find** | Search by name, content, size, date, attributes and duplicate detection across drives. |
| 🌐 **FTP and cloud** | Connect to FTP, SFTP and WebDAV locations and treat them like local folders. |
| 🧩 **Scripting and plugins** | Extend the app with VBScript, JScript or custom plugin DLLs for new columns and actions. |

## 🛠️ Troubleshooting

| Problem | Solution |
| --- | --- |
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes without a message | Confirm you are on a 64 bit Windows build and rerun the setup file as administrator. |
| Explorer replacement does not activate | Open Preferences, go to Launching Explorer, and re-enable the Explorer replacement option. |
| Tabs or layouts missing after update | Restore your configuration from the backup file in Preferences, Backup and Restore. |
| FTP connections time out | Check the passive mode setting in the FTP address book entry and test your firewall rules. |
| Viewer shows a blank preview | Install the matching Windows codec or switch the internal viewer to the plugin mode. |
| App feels slow on network drives | Disable thumbnail caching for remote paths in Preferences, Folder Display. |
